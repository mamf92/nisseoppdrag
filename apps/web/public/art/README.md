Illustrations for Nisseoppdrag, generated for this project and exported by the design thread
(AVIF and WebP). `badges/` holds the fifteen medallions at 256 px, `family/` the five Gården portraits.
The licence for the artwork is separate from the code and is not decided yet.
`gate/` has the login paintings (L-11 for Gården, R-11 for Låven) and `story/` the two story cards (L-12, R-10), each as AVIF and WebP at 1x and 2x.
`home/` has the Home paintings for when no week is open: R-13 and L-13 between weeks, R-14 and L-14b when the season is over.
